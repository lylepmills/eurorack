# Metalwork

Prototype struck-metal bank. Four sampled-on-trigger ratio sets distinguish
anvil, agogo, plate and gong, while paired oscillators add independently
controllable beating instead of baking one amount of shimmer into every object.
In stereo, the low body remains centred while opposing upper-mode pickups
spread the six modes across the field; mono AUX retains the upper-mode and
dry-strike extraction.
