# Skins

Prototype modal membrane percussion. Unlike the general Modal Resonator, the
strike position changes which head modes are excited, pressure shortens the
upper modes, and every hit begins with a controllable downward pitch bend.
In mono, OUT carries the full head while AUX isolates the rim-weighted upper
modes and dry slap. In stereo, the low body remains centred while opposing
upper-mode pickups spread the same eight resonators across a coherent L/R head.
